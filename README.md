## 问题 1：定位区域的构造、直径与覆盖判定

**建模思路**

1. 示向度误差有界 `|ε| ≤ 1°`，单次测向把源位置约束为张角 2° 的**楔形**——可写成两个半平面之交。
2. `n` 个楔形取交得定位区域 `K = ⋂ Wᵢ`，是**凸多边形**，边数至多 `2n`；用 Sutherland–Hodgman 半平面交在 `O(nm)` 内构造。
3. 直径化为凸多边形对踵点对问题，用**旋转卡壳**在 `O(m)` 内精确求解，与 `O(m²)` 暴力算法交叉验证。
4. 覆盖判定：设 `R*` 为 `K` 的最小包围圆半径（Welzl 算法），则「以 `K` 的直径为直径的圆」覆盖 `K` 的**充要条件**为 `R* ≤ d/2`。
5. 由 **Jung 定理**得 `d/2 ≤ R* ≤ d/√3`，即最坏需把直径放大 `2/√3 ≈ 1.1547` 倍，且该上界由等边三角形取等。

**主要结论**

| 项目 | 结果 |
|---|---|
| 基准算例（题图 2 复现） | `d = 87.938 m`，`R* = 43.969 m`，直径圆覆盖 ✓ |
| 反例（近等边三角形） | `R*/(d/2) = 1.010078`，直径圆**不**覆盖 |
| 无界情形（近平行示向线） | 与 1800 m 圆域取交后 `d = 1409.864 m` |
| 蒙特卡洛最差样本 | `R*/(d/2) = 1.129968` |
| 覆盖比例（每组 3000 次） | `n=2: 98.59%` → `n=3: 84.12%` → `n=4: 77.77%` → `n=6: 67.49%` |
| Jung 界紧性 | 等边三角形半径比 `1.154701 = 2/√3` ✓ |

**结论**：以定位区域直径为直径的圆**不能**保证覆盖该区域，须改用最小包围圆（半径至多放大 `2/√3` 倍）。

## 问题 2：第二检测点的最优选择与稳健选址

**建模思路**

1. 建立 Fisher 信息矩阵 / GDOP 误差传播模型，证明交会角 90° 时误差最小，近平行与共线构型发散。
2. 将两个楔形在源附近近似为等宽**条带**，交会区域近似为平行四边形，导出面积准则与直径准则的闭式解。
3. 用精确楔形半平面交 + 全顶点对暴力直径 + 三分搜索**独立复核**闭式解。
4. 引入可探测约束 `t ≤ √(R_eff² − r²)`（最坏 `R_eff = 1000 m`），得临界距离 `r ≤ 1000/√3 ≈ 577.35 m`。
5. 源距 `r` 不可观测，故推广为**先验集上的 minimax 稳健选址**，并给出候选区域而非单点。

**主要结论**

| 准则 | 闭式解 | 精确数值解 | 相对偏差 |
|---|---|---|---|
| 面积最小化 | `t* = r` | `t* = 1.002433 r` | +0.2433% |
| 直径最小化 | `t* = √2 r` | `t* = 1.416366 r` | +0.1522% |
| 最小直径 | `d_min = 6r·tan1°` | 精确值偏高 | +0.1117% |

精确复核覆盖 `r = 200 ~ 1450 m` 全档，`t*/r` 基本恒定，验证了闭式解的工程可用性。

**临界处理**：`r > 577.35 m` 时最坏情形下无单步可行 `t`，须先沿示向线前移，再于垂直方向按 `t* = √2 r'` 布点（两步策略）。

## 交叉验证与自检

`verification/selftest_geometry.txt` 记录 15 项断言，全部 PASS，包括：

- 旋转卡壳与暴力直径在 400 个随机凸多边形上**最大相对差 0**
- Jung 界 `d/2 ≤ R* ≤ d/√3` 在 300 个随机凸集上**越界 0**
- Thales 判据（最长边对角 ≥ 90° ⟺ 直径圆覆盖）与最小包围圆判定一致
- 题图 2 的两种读法（楔形交 vs 相邻边界线交点）顶点集一致

`verification/check_q4_coverage.txt` 是问题 4 的覆盖完备性验证：格距 `s ≤ 1000 m` 时，
4321 个采样位置（含全部朝向）**不可探测率 0**；`s = 1200 m` 时升至 38.28%。
